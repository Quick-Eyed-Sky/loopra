LOOPRA 0.1.1 — CALM, IN LAYERS

1. Keep this whole folder together. Python 3 is required.
2. On a Mac, double-click Run Loopra.command.
3. Keep its Terminal window open, then click Start listening in the browser.

If macOS blocks the downloaded launcher, read docs/first-opening.md.
For a trusted download, the usual path is:
System Settings > Privacy & Security > Security > Open Anyway.
Apple's explanation: https://support.apple.com/en-us/102445

Another way to start, from Terminal in this folder:
python3 scripts/serve.py --open

The footer says v0.1.1. Every layer has a headphone Solo button.
If an older Loopra tab is still open, use the fresh page opened by this launcher.

Source: https://github.com/Quick-Eyed-Sky/loopra
Full instructions: README.md
